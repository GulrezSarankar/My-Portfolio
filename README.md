## About

Software Engineer at **ISEES Technologies LLP**, working on Java-based backend systems since July 2024 and promoted to Software Engineer in January 2026.

My work centers on **REST API development**, **relational database integration**, and **production application development** using Java and Spring Boot. I focus on layered, clean architecture — keeping controllers thin, services expressive, and persistence well-separated — so systems stay maintainable as they grow.

Outside my primary role, I build full-stack and AI-assisted applications, and I write technical articles on Java backend architecture and Spring Boot best practices.
